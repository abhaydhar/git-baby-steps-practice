# Create Weekly Status Report

Write a Markdown status report with exactly these sections in this order:

## Accomplishments
- Use bullet points only.
- List completed work, milestones, and verified results.
- Keep each bullet factual and outcome-focused.

## Blockers
- Use bullet points only.
- List issues, risks, dependencies, or delays that affect progress.
- State the impact and ownership if known.

## Next Week
- Use bullet points only.
- List planned work and priority actions for the upcoming week.
- Keep items specific and time-bound when possible.

Requirements:
- Use Markdown headings and bullet points only.
- Keep the total output to 20 lines or fewer.
- Use a professional tone.
- Remove fluff words, marketing language, and filler text.
- Do not include tables, paragraphs, or extra commentary.
- Make the report concise and operational.
